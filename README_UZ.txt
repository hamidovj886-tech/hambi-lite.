HAMBI LITE — JAVA ANDROID LOYIHASI

YANGI VERSIYA:
- Sariq-qora zamonaviy interfeys.
- Bosh sahifa: balans kartasi, internet/daqiqa/SMS qoldiq kartalari, tezkor xizmatlar.
- Tariflar, Paketlar, Profil sahifalari.
- USSD tekshiruv tugmalari, rasmiy sahifalarga havolalar.
- PIN yaratish, PIN bilan kirish va PINni almashtirish.
- Maxsus ilova ikonkalari.

APK YIG'ISH:
1. ZIP faylni oching.
2. Ichidagi hambi_lite_android papkasini oching.
3. Uning ICHIDAGI fayl va papkalarni GitHub repozitoriyangizning asosiy sahifasiga yuklang (hambi_lite_android papkasining o'zini ichki papka qilib joylamang).
4. GitHub'da .github/workflows/build-apk.yml ham borligini tekshiring.
5. Actions -> Build Hambi Lite APK -> Run workflow.
6. Muvaffaqiyatli tugagach, Actions sahifasidagi Artifacts -> Hambi-Lite-APK ni yuklab oling.

MUHIM:
- Balans va paket qoldiqlari demo qiymatlar, haqiqiy operator ma'lumotlari emas.
- USSD tugmalari telefonning terish oynasini ochadi; foydalanuvchi o'zi davom ettiradi.
- Bu mustaqil prototip, Beeline/Hambi rasmiy ilovasi emas.
- Loyiha GitHub Actions'da hali real qurilmada sinovdan o'tkazilmagan; build natijasini tekshirish kerak.
